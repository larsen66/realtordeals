# Мои активности и мои рефералы

Разделы расположены в навигации сразу после «Сделок».

`/crm/activities`: расклейка, реклама в Telegram, промо стойка. Можно назначить дату и время, добавить комментарий, перенести активность, отметить выполнение и вернуть её в план. Счётчики показывают количество отметок выполнения за текущий календарный месяц по Москве; дата планирования на счётчик не влияет. Повторная отметка выполнения не меняет дату выполнения.

Активности сохраняются через Express `/activities` в Supabase `public.activities`. Перед запуском раздела примените `supabase/migrations/20260920090000_create_activities.sql`. При недоступности базы показывается ошибка, без подмены сохранения браузерным хранилищем. Обновления проверяют версию `updated_at` и отклоняют устаревшую запись с 409.

`/crm/referrals`: карточки покупателей на этапе `referral`, включая ранее созданные. Новая карточка создаётся через форму с телефоном, необязательным именем и комментарием. Комментарий хранится в `cards.fields.referralComment`, доступен для редактирования в таблице и полной карточке. Задачи и остальные поля карточки сохраняются. Для рефералов новая таблица не нужна.

Разделы используют существующий контур CRM одного агентства. Изоляция по менеджерам появится вместе с авторизацией существующего Express API; текущая система не имеет идентификатора вошедшего менеджера.

Проверки: `pnpm --filter api test`, `pnpm --filter api lint`, `pnpm --filter web lint`.
