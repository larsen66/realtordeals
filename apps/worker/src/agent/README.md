# Модуль агента Веры

Рабочие функции `OpenAiAgent.transcribe(file)` и `extract(input, schema)`. В первой локальной версии их вызывает Telegram-бот; затем этот же модуль переносится в worker Давида. Сам worker, Redis, база и применение результатов здесь не создаются.

Модуль не читает env самостоятельно: вызывающий код передает apiKey, textModel и transcriptionModel. Ключ только в окружении worker. Модели задаются явно, без автоматического перехода к другому поставщику. Зависимостей npm нет: Node.js 22+, встроенные fetch/File/FormData.

Вызовы используют прямой OpenAI API. Транскрибация возвращает текст; извлечение получает JSON Schema выбранной формы из packages/domain и функцию parse из той же схемы. Схема должна поддерживать неизвестные значения, вопросы и неразобранные сведения. Обязательность финальной карточки проверяется отдельно бэкендом: схема извлечения допускает неполный черновик.

Бот передает файл после проверки доступа/размера. Перед применением полей API проверяет версию черновика; запоздалый результат не затирает свежие исправления. Ошибки имеют безопасный код, без ключа и клиентского содержимого. После переноса в worker повторы будет регулировать очередь; модуль не повторяет запросы сам.

Автопроверки используют подмененный HTTP-клиент. Подключение ключа запускает обработку только после старта бота в `BOT_MODE=api`; рабочие схемы и API уже подключены, а очередь остается следующим этапом.

Документация: [транскрибация](https://developers.openai.com/api/docs/guides/speech-to-text), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
